GITHUB PAGES
1. Create a new GitHub repository, e.g. pen-epoxy-calculator.
2. Upload ALL files from this folder to the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and /(root), then Save.
6. Once GitHub provides the Pages address, open it in Safari on your iPhone.
7. Tap Share > Add to Home Screen. Enable Open as Web App if shown, then Add.
8. Open it once while online so the offline cache is installed.

The calculator assumes one tube per mold and subtracts tube displacement before adding overage.
Default overage: 10%.

UPDATED CALCULATION
Mold length is tube length + adjustable extra plug space. Extra mold length dropdown runs from 1/32 inch through 1 inch in 1/32 inch increments and defaults to 3/16 inch.
